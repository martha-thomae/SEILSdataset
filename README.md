# SEILSdataset-OMR-StaffLevel-Refined

This repository is a fork of the [SEILS dataset](https://github.com/SEILSdataset/SEILSdataset) that retains its original OMR-related resources and extends them with additional data and processing for staff-level Optical Music Recognition (OMR). The original repository contains both OMR-related and music-analytical resources for 30 madrigals, each represented in five partbooks (150 particellas in total).

This fork focuses exclusively on the OMR-related resources. In addition to preserving the original OMR ground truth, it introduces staff-level score images and corresponding Humdrum `**mens` encodings, specifically processed to facilitate training holistic staff-level image-to-sequence OMR models.

The information is distributed into two folders:
- The folder [**`SEILS_diplomatic_OMRgroundTruth`**](./SEILS_diplomatic_OMRgroundTruth) contains the **original OMR-related resources** from the SEILS dataset repository, preserved without modification.

  It is structured in the following subfolders:
  - [*`choral`*](./SEILS_diplomatic_OMRgroundTruth/choral): the thirty madrigals are encoded as chorales and saved into `MEI` (30 files) and Humdrum `**mens` (30 files).
  - [*`converters`*](./SEILS_diplomatic_OMRgroundTruth/converters): scripts used to transform the Humdrum `**mens` files (contained in the `particellas_codified` folder) into `agnostic` and `semantic` encodings, which are useful formats for OMR.
  - [*`particellas_OMRgroundTruth`*](./SEILS_diplomatic_OMRgroundTruth/particellas_OMRgroundTruth): `agnostic` and `semantic` files encoding the 150 particellas. These files were generated using the `converter` scripts over the Humdrum `**mens` files in the `particellas_codified` folder.
  - [*`particellas_codified`*](./SEILS_diplomatic_OMRgroundTruth/particellas_codified): `MEI` and Humdrum `**mens` files encoding the 150 particellas. These files were generated by extracting the individual voice information from the `MEI` and `**mens` files in the `choral` folder.
  - [*`particellas_engravedImages`*](./SEILS_diplomatic_OMRgroundTruth/particellas_engravedImages): renditions of the particellas contained in `particellas_codified`.
  - [*`particellas_original`*](./SEILS_diplomatic_OMRgroundTruth/particellas_original): PDFs of the 150 particellas.

  **The `agnostic` and `semantic` encodings (in *`particellas_OMRgroundTruth`*) and the images of the 150 particellas (in *`particellas_original`*) are the relevant resources for OMR.** The other folders contain intermediate files that allowed to generate said encodings. In particular, the workflow to get the agnostic and semantic encodings can be summarised as:
  1. *`choral`* scores encoded in `MEI` and `mens`
  2. *`particellas_codified`* in `MEI` and `mens`, extracted from _(i)_ via Humdrum
  3. *`particellas_OMRgroundTruth`* in `agnostic` and `semantic`, obtained from _(ii)_ via the *`converters`* scripts `mens2agnostic` and `mens2semantic`

- The folder [**`staff-based_OMRgroundTruth`**](./staff-based_OMRgroundTruth) contains the **new resources** introduced in this repository.

  **See the [README](./staff-based_OMRgroundTruth/README.md) in the `staff-based_OMRgroundTruth` folder to know more about these resources and their generation.** These resources are intended to provide ready-to-use ground truth for image-to-sequence models that take as input individual staff-region images and output the sequence of music symbols contained in them. The folder contains:

  - **Staff-region images:** Images corresponding to the individual staff regions, obtained by segmenting the full-page images of the SEILS dataset. These regions were manually annotated using Label Studio.
    
    **-\>**  **For more details**, consult the ["A) Generating the images"](./staff-based_OMRgroundTruth#a-generating-the-images) section in the `staff-based_OMRgroundTruth` README.
    
  - **Staff-region encoding:** Humdrum `**mens` encodings corresponding to the individual staff regions. These files were derived from the original `**mens` particellas in [`particellas_codified`](./SEILS_diplomatic_OMRgroundTruth/particellas_codified) and subsequently processed to:
    - Segment the original encodings into individual staves.
    - Remove information from the original encodings that is not relevant for the OMR task.
    - Subtokenize the encodings to obtain the desired representation of the musical symbols.
    
    **-\>**  **For more details**, see the ["B) Generating the sub-tokenized \*\*mens encodings"](./staff-based_OMRgroundTruth#b-generating-the-sub-tokenized-mens-encodings) section in the `staff-based_OMRgroundTruth` README.

    The resulting files provide staff-level ground truth corresponding to the staff-region images and are intended for direct use in staff-level image-to-sequence OMR models.
 
The additional staff-level resources in this repository are intended to facilitate the training and evaluation of holistic staff-level Optical Music Recognition (OMR) models. The repository provides both the visual input (staff-region images) and the corresponding symbolic ground truth (Humdrum `**mens` encodings, either in their original or subtokenized form, depending on the researcher's preference). These resources allow researchers to train and evaluate OMR models without having to perform the staff-level segmentation and symbolic-data preprocessing themselves.



Please consult the original [SEILS dataset](https://github.com/SEILSdataset/SEILSdataset) repository to learn more about the original dataset, the pieces and composers included in it, its intended uses for OMR and for music analysis (including digital editions), and related publications.
